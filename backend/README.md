# Backend

## Services

- `auth-service`
- `parking-service`
- `car-service`
- `report-service`
- `api-gateway`

## Commands

```bash
npm run dev:all
npm run dev:auth
npm run dev:parking
npm run dev:car
npm run dev:report
npm run dev:gateway
npm run build
npm run seed:admin
```

## Environment

Use `.env.example` as the reference. The local `.env` is configured for PostgreSQL on `localhost`.
